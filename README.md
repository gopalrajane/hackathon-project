🏜️ YOLO Training Model: Offroad Segmentation

Project: Duality AI Offroad Segmentation Challenge
Team: Tech Sorcerer (Aditya Waje, Girish Unde, Gopal Rajane)


📌 Problem Statement

Autonomous vehicles perform effectively on structured roads but face significant challenges in off-road environments such as deserts and uneven terrain.

These environments lack clear lanes, markings, and consistent structure, making it difficult to identify safe paths. Additionally, obstacles like rocks, bushes, and natural terrain variations are hard to detect reliably.

A key technical issue arises from the available dataset itself. The synthetic segmentation masks generated by the simulator use non-standard, high-value class IDs (ranging from 100 to 10,000). These values are incompatible with standard deep learning training pipelines and can lead to instability or failure during model training.

As a result, there is a need to:

Process and normalize such data into a usable format
Train a segmentation model capable of accurately understanding off-road scenes

Without addressing these challenges, autonomous systems cannot safely and effectively operate in unstructured environments.


💡 Solution

To address the challenges of off-road segmentation and unstable training data, we implemented a structured deep learning pipeline using synthetic desert images.

✔️ 1. Data Preprocessing (Key Fix)

The raw segmentation masks contained high-value class IDs (100–10,000), which caused training issues.

We solved this by:

Remapping all class values into a 0–9 range
Ensuring compatibility with the model and loss functions
Stabilizing the training process
✔️ 2. Model Training

We used a DeepLabV3+ segmentation model with a ResNet-50 backbone.

Initialized with ImageNet pretrained weights
Trained on labeled synthetic images
Learned pixel-level classification of terrain
✔️ 3. Handling Class Imbalance

Some classes (like sky) dominate, while others (like small objects) are rare.

To handle this:

Used a hybrid loss function (Dice + Focal Loss)
Improved learning for both large and small classes
✔️ 4. Efficient Training Strategy
Trained on smaller subsets (e.g., 100 images) for faster iteration
Enabled quick testing and debugging of the pipeline
✔️ 5. Prediction & Output

After training:

Model takes a new image as input
Produces a pixel-wise segmented output
Helps identify terrain like rocks, bushes, and ground

🎯 Final Outcome

The system provides a stable and functional segmentation pipeline that:

Handles non-standard dataset formats
Learns terrain classification effectively
Generates usable predictions for off-road understanding
